# Лабораторная работа № 1

**Дисциплина:** Технологии программирования

**Тема:** Работа с системой контроля версий Git

**Выполнила:** Хужамова Тасмина, БИВТ-25-4-6

## Цель работы

Освоить создание локального репозитория, фиксацию изменений и отправку коммитов на GitHub.

## Задание

Создать репозиторий, сделать коммит, подключить удалённый репозиторий и отправить в него изменения.

## Ход выполнения

В Git Bash создан локальный репозиторий командой `git init`. Файл `README.md` добавлен в индекс командой `git add README.md` и сохранён в коммите `Initial commit`.

После проверки SSH-подключения репозиторий GitHub добавлен под именем `origin`. Ветка `main` отправлена командой `git push -u origin main`.
